В ходе выполнения лабораторной работы был разработан скрипт, предназначенный для сбора информации об операционной системе и окружения пользователя. Программа поддерживает такие операционные системы, как Windows, Linux и MacOs. Собранные данные сохраняются в файл system_info.json в той же директории, что находится скрипт.

Программа собирает следующие сведения:
1. операционная система: название, системное обозначение, версия, архитектура, тип машины и информация о процессоре.
2. python: версия интерпретатора, его реализация и путь к исполняемому файлу.
3. компьютер: имя компьютера, имя текущего пользователя, текущий рабочий каталог и домашний каталог пользователя.
4. окружение: время сбора данных, идентификатор процесса, количество логических процессоров и кодировка файловой системы.
5. сеть: имя компьютера в сети, полученное с помощью системного имени узла.
